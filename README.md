# Build AI Agents With Claude Models on Microsoft Foundry

> This workshop is part of the [Model Mastery](https://aka.ms/model-mastery) series of workshops for Microsoft Foundry.
> Each lab is modular and can be used for instructor-led sessions (in venue) and self-guided learning (at home).

## About This Workshop

Want to build more effective AI agents with [Anthropic](https://ai.azure.com/catalog/models?publisher=anthropic) models on Microsoft Foundry? 
This hands-on workshop will give you a deeper understanding of the Claude family of models and teach 
you to build, evaluate, and deploy, effective AI agents with these models on Microsoft Foundry.
